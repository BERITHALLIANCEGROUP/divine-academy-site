DIVINE ACADEMY — prototype du site web

Fichiers
- index.html : contenu et structure du site
- styles.css : mise en page responsive
- script.js : menu mobile et démonstration du formulaire
- logo.jpg : ajouter ici le logo officiel fourni

IMPORTANT
Ce projet est un prototype. Le formulaire ne transmet pas les données à l’administration :
il génère seulement un fichier texte local pour montrer le parcours. Avant la mise en ligne
publique, il faut connecter le formulaire à un service de réception fiable et ajouter l’adresse
e-mail officielle, le téléphone et le WhatsApp confirmés par la Direction.

Déploiement gratuit suggéré : GitHub Pages
1. Créer un dépôt GitHub public nommé divine-academy-site.
2. Téléverser index.html, styles.css, script.js et logo.jpg à la racine du dépôt.
3. Dans Settings > Pages, choisir le déploiement depuis la branche principale (main), dossier /(root).
4. Enregistrer et attendre l’URL fournie par GitHub Pages.
5. Tester le site sur téléphone et ordinateur avant de le partager.
